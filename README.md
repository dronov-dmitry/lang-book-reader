# LangBookReader

Приложение для чтения и перевода книг на иностранных языках.

## Возможности

- **Чтение книг** в форматах EPUB, FB2, TXT
- **Перевод слов и предложений** при нажатии — встроенный переводчик MyMemory и DeepL
- **Выделение текста** — выделяйте фрагменты длительным нажатием
- **Словарь** — сохраняйте переведённые слова для повторения
- **Библиотека** — храните все книги в одном месте, отслеживайте прогресс
- **Авторизация через Google** — синхронизация между устройствами
- **Закладки** — сохраняйте позицию чтения
- **Тёмная тема** — удобное чтение в любое время суток
- **Озвучивание текста** — прослушивайте выделенные фрагменты
